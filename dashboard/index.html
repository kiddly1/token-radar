How the number is built

implied value = TVL × category multiple × growth × maturity

Category multiple

The median market-cap / TVL ratio of the live-token protocols in the same category, computed from this snapshot. Fewer than 3 live peers in a category? The overall live median is used instead. Multiples are clamped to 0.05–1.50.

Growth & maturity

Growth is the 7-day TVL change, clamped to −60%…+120% and given half weight: 1 + change × 0.5. A protocol shrinking fast scores 0.70; one growing 120% scores 1.60.

Maturity rises with how long the protocol has run with no token: 0.60 at launch, 1.00 after 3 years. Age unknown means 365 days.

What counts as pre-token

The snapshot records no token when market cap, Gecko id and symbol are all empty. Wrapped, staked, bridged and exchange products are excluded — their receipt tokens already trade. We say “records no token”, never “has no token”: the snapshot is not proof.
